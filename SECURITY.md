# Security Policy

We take the security of TACEO software seriously. Thank you for helping us keep our users safe.

## Reporting a vulnerability

Please **do not** open a public issue for security related issues.

- Preferred: use **"Report a vulnerability"** in the Security tab of the affected repository (GitHub private vulnerability reporting).
- Alternatively, email **<security@taceo.io>**.

Please include the affected repository and version/commit, a description of the issue and its impact, and steps to reproduce or a proof of concept.

If you have reason to believe a vulnerability is being actively exploited or has severe impact, mark your report as **CRITICAL** in the report subject.

## What to expect

- We will acknowledge your report as soon as possible, usually a few business days.
- We keep you updated while we investigate and fix the issue, and coordinate disclosure with you.
- We credit reporters in the advisory unless you prefer to stay anonymous.

## Scope

This policy covers repositories in the TaceoLabs GitHub organization. Many repositories are research code, forks or demos that are not maintained for production use. Please still report issues there, but fixes may not be prioritised. Issues in third-party upstream projects should be reported to their maintainers as well.
